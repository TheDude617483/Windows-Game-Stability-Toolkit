Windows Game Stability Toolkit
A comprehensive collection of tools, scripts, diagnostics, and guides designed to help PC gamers identify crashes, improve stability, and optimise performance across Windows titles — especially heavily‑modded games like GTA V and RDR2.

🚀 Purpose
Modern PC games often suffer from instability, crashes, and performance issues — especially when mods, scripts, or custom configurations are involved.
Most solutions online are outdated, scattered across forums, or overly technical.

This project solves that by providing:

Clear, beginner‑friendly troubleshooting guides

Automated diagnostic scripts

Stability‑focused optimisation tools

Consistent updates based on real user issues

The goal is to make game stability simple, repeatable, and accessible for everyone.
