# GTA V Crash Troubleshooting Guide

This guide helps diagnose common GTA V crashes on Windows 10/11.

## Common causes
- Outdated game files  
- Corrupted mods  
- ScriptHook conflicts  
- GPU driver instability  
- Missing redistributables  

## Quick fixes
1. Verify game files  
2. Remove recent mods  
3. Update ScriptHookV  
4. Reinstall VC++ redistributables  
5. Clear shader cache
